# HELIX---Interactive 3D DNA Explorer
HELIX is an interactive 3D DNA explorer built with HTML, CSS, JavaScript, and Three.js. Explore a scientifically grounded DNA double helix, select nucleotides (A, T, C, G), view biological information, and interact with the molecule through real-time rotation, zoom, and camera controls.

## Key Features
- **3D Molecular Visualization:** Interactive representation of the DNA double helix.
- **Nucleotide Exploration:** Explore adenine (A), thymine (T), cytosine (C), and guanine (G).
- **Interactive Controls:** Camera rotation, zoom, and view reset.
- **Dynamic Information Display:** Nucleotide properties and complementary base-pair relationships.
- **Modern Interface:** Minimal, responsive design optimized for scientific exploration.

## Technology Stack
- HTML5
- CSS3
- JavaScript
- Three.js

## Getting Started

Open `index.html` in a modern browser or use the VS Code Live Server extension.

*An internet connection may be required to load external libraries.*

## Scientific Foundation

The visualization incorporates DNA's antiparallel strand organization and canonical complementary base pairing: adenine–thymine (A–T) and guanine–cytosine (G–C).
